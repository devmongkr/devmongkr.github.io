새로운 기술과 창의적인 디자인으로 아이디어를 사용자 중심의 모바일 앱으로 연결합니다.

WHAT WE DO

우리가 만드는 서비스

아이디어가 서비스로 완성되는 과정, 필요한 개발 경험을 함께합니다.

iOS 앱 개발

Swift와 SwiftUI를 활용한 네이티브 iOS 앱. 자연스러운 사용 경험과 안정적인 성능을 고려합니다.

  • Swift
  • SwiftUI
  • UIKit
  • Core Data

Android 앱 개발

Kotlin과 Jetpack Compose 기반의 Android 앱. 다양한 기기와 환경에 맞는 모바일 경험을 설계합니다.

  • Kotlin
  • Jetpack Compose
  • Room
  • Coroutines

크로스 플랫폼 개발

Flutter와 React Native를 활용해 iOS와 Android를 함께 개발하고, 일관된 서비스 경험을 구현합니다.

  • Flutter
  • React Native
  • Dart
  • TypeScript
